# Формат проекта `.ktproj` (v1)

JSON через serde. Обратной совместимости со старым `.kpproj.json` (C++ версия) **нет** — решение пользователя. Чтение толерантно к неизвестным полям (forward-compat); `format_version` читается и проверяется (в отличие от старого формата, где version писался и игнорировался).

```jsonc
{
  "format_version": 1,
  "settings": {
    "fps": 30,                  // сетка видео-кадров
    "width": 1920, "height": 1080,
    "sample_rate": 48000        // всегда 48000 в v1; поле — на будущее
  },
  "media": [
    { "id": 1, "path": "clips/interview.mp4" }   // путь относительно файла проекта
  ],
  "clips": [
    {
      "id": 10,
      "link_group": 3,          // A/V-линк; null = не связан
      "kind": "video",          // "video" | "audio"
      "lane": 0,                // z-order для видео, микс-дорожка для аудио
      "start": 0,               // ВСЕ времена — в тиках 1/90000 c, не в мс
      "duration": 900000,       // 10 c
      "source_in": 180000,      // in-point в источнике, тики
      "media": 1,
      "gain_db": 0.0,
      "fx": [
        {
          "kind": "slowed_reverb",          // типизированный enum, не сырой JSON
          "params": { "rate": 0.82, "mix": 0.3, "reverb_delay_ms": 140.0 },
          "automation": [ { "t": 0.0, "param": "rate", "value": 0.82 } ]
        }
      ]
    }
  ]
}
```

Отличия от старого формата и почему:
- **Тики вместо мс** — lossless относительно сетки fps и аудио-burst.
- **Таблица `media`** вместо повторения абсолютного пути в каждом клипе; пути относительные → проект переносим. Sidecar индекс-БД лежит рядом: `<project>.ktindex.db` (см. `media-index.md`), в git/бэкапы не входит — пересоздаётся.
- **Типизированные FX-параметры** (serde enum) вместо opaque `QJsonArray` — валидация на загрузке, никаких молчаливых выбрасываний битых клипов: ошибка загрузки является ошибкой.
- Snapshot-undo не сериализуется; view-состояние (зум, скролл, курсор) — отдельная секция `ui` (опциональная, потерять не жалко).

Источник правды по схеме — типы в `src/libs/kt-model/src/project.rs` + тест 12 (round-trip, байт-стабильность save→load→save).

`ui.lane_order` (v1.4, п.6): display-порядок дорожек сверху вниз — массив пар `[kind, lane]`, kind ∈ `video|audio|morph`. Чисто визуальное свойство (семантика ClipEvent.lane не зависит); пусто/отсутствует = блочный порядок V..A..M; нормализация выбрасывает мусор и дописывает недостающие.
