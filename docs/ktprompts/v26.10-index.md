# Registry of the claims file `v26.10`

Source — [`v26.10.txt`](v26.10.txt) (verbatim, the owner's file `ktprompts_v26.10`).
Cross-check against the code and the specs — `openspec/changes/r71-ktprompts-index/design.md` §3
(state as of 12.10.2026); the owner's answers — `docs/user-feedback.md`, round R.71.

How to read a row: `#` — the item's name (the file restarts its numbering in each block, so
the name is `<block letter><number>`); `Line` — the source line(s) of the item; `State` — one of
`done` (round and test), `partial` (what exists / what is missing), `no` (a defect → capability,
a feature → note or "no note"), `question` (the text of the question to the owner), `future`;
`Stage` — the round that takes the item, or "later". LC — "check live in the round that takes
the item". The guard — `python3 src/scripts/ktprompts-index.py --check`: every numbered line
of the source must fall into the `Line` of some row.
