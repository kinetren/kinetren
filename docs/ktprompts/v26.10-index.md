# Registry of the claims file `v26.10`

Source — [`v26.10.txt`](v26.10.txt) (verbatim, the owner's file `ktprompts_v26.10`).
Cross-check against the code and the specs — `openspec/changes/r71-ktprompts-index/design.md` §3
(state as of 12.10.2026); the owner's answers — `docs/user-feedback.md`, round R.71.

How to read a row: `#` — the item's name (the file restarts its numbering in each block, so
the name is `<block letter><number>`); `Line` — the source line(s) of the item; `State` — one of
`done` (round and test), `partial` (what exists / what is missing), `no` (a defect → capability,
a feature → note or "no note"), `question` (the text of the question to the owner), `future`;
`Stage` — the round that takes the item, or "later". The order of the rounds is the owner's answer to question 11 (2026-10-30): R.72 timeline and transport → R.73 generators → R.74 render → R.75 ducking by role → R.76 windows and glow → R.77 automation and presets → R.78 project scale; the open changes of `kkt-26.10.27` and `v26.10.18` go before all of them. LC — "check live in the round that takes
the item". The guard — `python3 src/scripts/ktprompts-index.py --check`: every numbered line
of the source must fall into the `Line` of some row.

## What OTIO export loses

The owner's requirement (CORE section): "any agent that adds any new feature that breaks otio must
record it in a separate list". A model change that the OTIO exchange file (`kt-otio` export) cannot
express gets a row here: what is lost, since which change, how export degrades it.

| Since | What the model has | What the `.otio` export does with it |
|---|---|---|
| shape-masks (2026-11-01) | Masks of an event's picture, of its effect slots and of a track: shapes, feather, modes, curves | Carried only in `metadata["kt"]` (the clip and track envelopes, v14 by content); a foreign editor shows the event unmasked and the masked effect over the whole frame |
| sim-audio-pairs (2026-11-03) | The audio half of a simulated device (`vhs_tape_sound`, `datamosh_sound`, `camera_isp_sound`) mirrored across an A/V link group, and held by a morpher patch beside its picture half (fx-graph, 2026-11-18); the device's sound rows on its video slot | Carried only in `metadata["kt"]` like every effect slot (v16 by content when a sound row is set); a foreign editor plays the event's own sound, without the device |
| planned: subtitles-and-text-editing (design 2026-11-20) | Transcripts (words in material time) and subtitle tracks with captions, styles and the karaoke highlight | Carried only in `metadata["kt"]` (by content); the export writes a sidecar `<name>.srt` per subtitle track beside the `.otio`; a foreign editor shows no captions until it imports the `.srt`, and never the transcript |
| track-device-sound (2026-11-20) | A video track's sound track (`Track.sound`) and the device sound halves mirrored onto that audio track's chain | The link is carried only in the track envelope `metadata["kt"]` (`sound`, v17 by content); a foreign editor sees two independent tracks, the sound half an unknown `kt:` effect on the audio track's `effects` |
| planned: frame-format-variants (design 2026-11-20) | Frame formats of one edit (rasters, per-event framing overrides, presence per format, per-format track masks) | The exchange file is the master edit; formats and overrides are carried only in `metadata["kt"]`; a foreign editor sees only the 16:9 framing |
| planned: multicam (design 2026-11-20) | Multicam compositions (angles) and the active angle and sound choice of each instance piece | The nested stack is written with only the active angle's tracks enabled; the multicam and the selection only in `metadata["kt"]`; a foreign editor plays the right angle per piece but cannot switch |
| planned: point-tracker (design 2026-11-20) | Trackers of an event (points or a plane; samples or homographies per material frame) and links to their channels | Carried only in the clip's `metadata["kt"]`; a foreign editor sees the linked parameters at their static values, without motion |
| planned: magic-wand-mask (design 2026-11-20) | Wand masks (seeds, tolerance, contiguous/colour range) recomputed per frame from the picture | Carried only in `metadata["kt"]` like every mask; a foreign editor shows the event unmasked |
| planned: auto-ducking-by-role (design 2026-11-20, revised 2026-11-22) | Audio roles, Auto-ducking rules (content ducking keyed by several tracks or roles; raise or mute during titles) | Carried only in `metadata["kt"]` of the clip and track envelopes (by content); a foreign editor plays the background un-ducked |
| planned: title-word-effects (design 2026-11-20) | Text-range masks on a title (the glyphs of a range of its text) and the isolate mask mode | Carried only in `metadata["kt"]` with the other masks (by content); a foreign editor shows the effect over the whole title |
| planned: loudness-norms (design 2026-11-22) | The project's loudness target and the program stage (a gain and a true-peak limiter on the master) | Carried only in `metadata["kt"]`; the export writes the event gains but a foreign editor plays the mix without the program stage |
| planned: motion-driven-params (design 2026-11-20, revised 2026-11-22) | Links to the outer speed of a time map (an instance's, a morpher's, an event's warp): speed, acceleration, speed change | Carried only in `metadata["kt"]` with the other links (by content); a foreign editor sees the parameter's static value |
| planned: real-3d-groups (design 2026-11-20) | 3D tracks drawn as groups with depth, extruded masks | Carried only in `metadata["kt"]` (by content); a foreign editor stacks the layers in 2D by track order |
