# F-HLP-034 — Справка и дополнение в поле формулы — без попапов

## Суть

Монтажёр открывает поле формулы и видит, что можно написать: рядом свёртываемая
«Справка» перечисляет переменные (`t`, `k`, `src`, `s`, `a`, `b`) с назначением и все
функции с числом аргументов; строка состояния у поля повторяет переменные; неверное имя
называется с ближайшими похожими; Tab дописывает имя по набранному префиксу — прямо в
поле, без списка поверх интерфейса.

## У кого и как

| Редактор | Версия | Как называется | Как устроено |
|---|---|---|---|
| Vegas Pro | 2026.0 | — | формул нет |
| Adobe Premiere | 26 | — | формул нет |
| DaVinci Resolve | 21 | Fusion → Expression field | подсказок нет; список функций — только в справке; ошибка — красная рамка без текста |
| Final Cut Pro | 12.3 | — | формул нет |
| After Effects | 26 | Expression Language Menu (▶ у поля) | ВСПЛЫВАЮЩЕЕ меню-дерево вставляет шаблон вызова в текст; ошибка — жёлтый значок и текст в панели с номером строки |

**Вне ядра.** Blender и VS Code показывают два предела: панель Python-подсказок и полноценный
автокомплит с попапом.

|---|---|---|---|
| Blender | 5.2 | Driver editor + Python tooltips | выражение с ошибкой подчёркивается, текст ошибки в панели драйвера; подсказки — всплывающие |
| Visual Studio Code | 1.136 | IntelliSense | попап с кандидатами, Tab принимает; сортировка по префиксу |

## Фишка фишки

1. **У After Effects справка по языку — это МЕНЮ ВСТАВКИ, а не документ:** пункт меню
   вставляет `wiggle(freq, amp)` с именованными аргументами в текст. Форма подсказки
   «вставь образец» ценнее, чем «прочти список» — но у AE это попап, а у нас попапы
   запрещены (правило 10, `ui-reach`). Наш эквивалент: клик по функции в группе «Справка»
   вставляет образец вызова в поле на позицию курсора.
2. **Ошибка с позицией — редкость:** Resolve красит рамку и молчит, AE называет строку.
   Наш вычислитель уже возвращает позицию символа (F-AUT-007); справка — это показать её
   человеку и добавить «ближайшие имена» (`floor` для `flor`), чего не делает никто из
   пяти.
3. **Tab-дополнение без попапа существует в оболочках тридцать лет** (bash: единственный
   кандидат — дописать, несколько — до общего префикса, список — отдельной строкой).
   Это ровно та форма, которая уживается с запретом всплывающих слоёв: список кандидатов
   уходит в строку состояния.

## Плюсы

- Ни одного слоя выше `Order::Middle` (t83 остаётся зелёным); справка — часть блока, не
  окно и не попап.
- Содержимое группы строится из реестра вычислителя — не вторая копия языка.
- Ошибка называет имя и ближайшие — правило 16 (невозможность — ошибка с причиной).

## Минусы

- Группа «Справка» занимает место в блоке — свёрнута по умолчанию, память egui.
- Tab в поле формулы перехватывается у навигации по полям; в других полях Tab прежний.

## Что говорят пользователи

НЕТ ЦИТАТ: разведка велась по справке After Effects (Expression Language Menu), Resolve
Fusion (Expression), Blender (Drivers) и VS Code (IntelliSense); поиск по площадкам не
проводился — требование дословно от владельца (`docs/user-feedback.md`, Р.67: «вообще не
понятно что можно указать в формулы кривых, никакой справки, никаких подсказок в момент
ввода и т.д.»).
