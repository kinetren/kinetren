# F-AUD-012 — Stereo Width (mid/side-ширина)

## Суть

Одна ручка «уже ↔ шире»: 0 — моно, 1 — как записано, 2 — разведено.
Монтажёру это «сузить музыку под голос», «сделать подложку моно, чтобы
диалог сидел в центре», «раздуть эмбиенс». Классическая mid/side-матрица.

## У кого и как

| Редактор | Версия | Как называется | Как устроено |
|---|---|---|---|
| Vegas Pro | 2026.0 | Pan/Expand | совмещает панораму и ширину; expand — тот же s-канал |
| Adobe Premiere | 26 | Stereo Expander | одна ручка ширины + центр-частота «раздува» |
| DaVinci Resolve | 21 | Stereo Width (Fairlight FX) | width 0..2, отдельный m/s-баланс |
| Final Cut Pro | 12.3 | Stereo Spread (Logic) | спектральный вариант: полосы раскидываются между каналами |
| After Effects | 26 | Stereo Mixer | по сути громкости/паны каналов; честной m/s-ширины нет |

## Фишка фишки

Настоящая тонкость — тождество на единице: наивная реализация
(l=m+s·w; r=m−s·w через float-матрицу) на width=1 НЕ байт-равна входу
(две операции с плавающей точкой на сэмпл), и зрелые реализации либо
короткозамыкают единицу, либо честно документируют «всегда обрабатывает».
Вторая деталь: Premiere «раздувает» не всё, а от настраиваемой частоты
вверх — низ остаётся моно, чтобы бас не расползался (моно-совместимость).
Третья: width применяется ДО панорамы события, иначе пан двигает уже
раздутую картину и центр уезжает.

## Плюсы

- Один параметр, нулевое состояние, нулевой хвост — предельно дешёвый
  эффект с большим практическим спросом («музыку уже, голос в центре»).
- Матрица уже написана и проверена в проекте (ширина хвостов реверба).

## Минусы

- width > 1 ухудшает моно-совместимость (s растёт против m) — сумма в
  моно тише и «фазит»; это свойство приёма, не дефект реализации.

## Как ложится на Kinotrain

### Что уже есть

- Матрица m/s уже написана в хвостах реверба:
  `let (a, b) = (0.5 + 0.5*width, 0.5 - 0.5*width)` в
  `src/libs/kt-fx/src/lib.rs` (Freeverb::process) — выносится в общий
  примитив и используется узлом.

### Чего не хватает

Только узла-обёртки (после узловой цепочки — ~30 строк).

### Что мешает

Ничего.

### Какие инварианты задевает

1 (f32-тракт). Байт-тождество на width==1.0 обеспечивается явным
пропуском обработки (m/s-переупаковка не байт-тождественна).

## Оценка

| Что | Ответ |
|---|---|
| Объём | S |
| Где основная работа | kt-fx (узел ~30 строк) |
| Формат проекта | не трогает |
| Тесты, которые придётся написать | width 0 ⇒ l==r; width 1 ⇒ байт-пропуск; width 2 растит s-энергию |
| Зависит от | узловой цепочки |
| Ломает совместимость | нет |

## Вердикт

Берём в Р.47: одна ручка width 0..2 с явным пропуском на 1.0. Частотный
сплит Premiere («низ моно») — не берём: одна ручка покрывает задачи
монтажа, сплит — материал для отдельной заметки, если попросят.
