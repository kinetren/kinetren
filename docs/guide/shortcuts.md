# Keyboard and mouse

## Transport

| Key | Action |
|---|---|
| **Space** (tap) | play / pause; a second tap right after pausing returns to the start |
| **Space** (hold) | play faster, ramping up to 4×; release to return to normal speed |
| **A** / **Home** | back: previous marker, region edge or event edge |
| **D** / **End** | forward: next marker, region edge or event edge |
| **Shift+A** / **Shift+D** | jump and drag the region edge along |
| **Shift+Home** / **Shift+End** | the very start / end of the project |
| **Ctrl+L** | jump to a typed timecode (digits fill from the right, Enter jumps) |
| **L** | loop the region |

## Editing

| Key | Action |
|---|---|
| **S** | split at the playhead, or cut out the region |
| **Delete** / **Backspace** | delete |
| **Ctrl+Z** | undo |
| **Ctrl+Shift+Z** / **Ctrl+Y** | redo |
| **Ctrl+C** / **Ctrl+V** | copy / paste at the playhead |
| **Ctrl+S** | save |
| **Ctrl+F** | search the project (↑/↓ choose, Enter jumps, Esc closes) |
| **M** | marker at the playhead (toggle) |
| **I** / **O** | region start / end at the playhead |
| **Alt+M** / **Alt+S** | mute / solo the selected event's track |
| **Enter** | expand the selected reel in place; again — open it |
| **Esc** | step back: close the top window, clear region and selection, collapse, leave the reel |

## Mouse on the timeline

| Gesture | Action |
|---|---|
| click the ruler, drag | move the playhead, scrub |
| drag on empty space | region |
| **Ctrl+drag** on empty space | select events |
| wheel / **Ctrl+wheel** | scroll / zoom around the mouse |
| **Shift+wheel** / **Ctrl+Shift+wheel** | scroll tracks / track height |
| drag an event (**Ctrl** — no magnet) | move |
| double-click an event | effects window |
| **Shift+double-click** an event | region over it |
| drag a top corner of an event | fade |
| drag the level line | opacity / gain; double-click — full / 0 dB |
| drag a transition's edge / its cut | resize / roll |
| double-click a transition | transition properties |
| double-click a reel | expand in place / collapse |
| double-click a morpher | morpher editor |
| drag a track header / its bottom edge | reorder / height (right-click resets) |
| right-click anything | its menu |

The status line always shows what the thing under the mouse does.
