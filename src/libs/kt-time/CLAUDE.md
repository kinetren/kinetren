# kt-time

Модель времени всего движка. Ноль зависимостей (кроме serde).

## Инварианты
- Тик = 1/90000 c, `i64`. Всё внутреннее время и весь формат проекта — только тики. Миллисекунды существуют лишь на границе UI (`Tick::as_ms`).
- `AUDIO_BURST_TICKS = 1920` — точное целое; границы аудио-burst'ов взаимно-однозначно конвертируются в номера сэмплов (тест `audio_burst_step_is_exact`). Не менять 90000/48000/1024 по отдельности — они согласованы.
- `FpsGrid::new` паникует на fps, не делящем 90000 — сетка кадров обязана быть целочисленной.
- Отрицательные тики валидны (floor-семантика через `div_euclid`) — на них опирается индексация до нуля.
