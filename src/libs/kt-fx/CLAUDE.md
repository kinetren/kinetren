# kt-fx

Аудио/видео-FX. Без FFmpeg/аудио-железа. Реализация — M6, трейты стабильны с M2.

## Инварианты
- `process()` видит только f32 48kHz/2ch interleaved (инвариант №1). Никаких sample-rate источника (дефект a — главная причина хрипов старого slowed&reverb).
- `set_params()` сглаживает и не трогает буферы; полный сброс — только `reset()` при seek (дефект e).
- `tail()` честно сообщает хвост; граф на него полагается (дефект f).
- Состояние FX не разделяется между потоками — им владеет аудио-render-поток (дефект b). Трейт Send, не Sync — это осознанно.
- slowedreverb: варispeed через rubato SincFixedOut с дробным fixed-point курсором источника (никаких пропусков/дублей burst'ов — дефекты c, d); реверб — freeverb-топология.

## Тесты (регрессии на хрипы)
- 4: спектральный (440→220 Гц при rate 0.5, боковые < −60 dBFS).
- 5: ступенька параметра → нет скачка сэмпл-к-сэмплу.
- 6: хвост за границей клипа; правка чужого клипа хвост не трогает.
