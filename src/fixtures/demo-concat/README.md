# Demo: concatenation of transforms (R.44), softening of barriers (R.45),
# decode scale step (R.46)

Projects for checking by eye and for comparison with the old engine. The media is
generated by the system ffmpeg (it is not committed to the repository):

```bash
./gen-media.sh
```

Open in `kt-app` (or render with `kt-cli export <project> out.mp4`).
The projects are regenerated by the test
`cargo test -p kt-cli --test gen_demo -- --ignored`.

| Project | What to look at |
|---|---|
| `01-net-identity.kt` | Three events of 4 s each: a clean source → a 2×2 grid mosaic + pan3d zoom ×4 (net scale 1:1) → a 2×2 grid + Pan zoom ×2. **All three MUST be equally sharp** (test: the running timecode of testsrc2 is readable). Before R.44 events 2–3 were soft — the grid was rasterised, and the zoom magnified the mush. |
| `02-user-parallax.kt` | The owner's scenario of R.44 with curves: grid → pan3d (the parallax comes back to normal by 4 s) → grid → pan3d (zoom ×4 at 7.5 s removes the grids). **The finale is sharp**, the timecode is readable. |
| `03-barrier.kt` | R.45, K×-barriers: grid → VHS → zoom ×2; grid → Edges → zoom ×2; a clean VHS (the reference of the look). **The effect's texture survives the zoom**: the scan lines/contours are crisp, the timecode is readable; the VHS look in event 1 matches the reference of event 3. |
| `04-pointwise.kt` | R.45, point-wise in a series (on green.mp4): a clean greenscreen (reference) → grid → greenscreen → zoom (the key works, the picture is sharp) → grid → noise → zoom (the grain is nailed to its own step — stretched into blocks by the zoom). |
| `05-decode-scale.kt` | R.46, decode scale step. Four events of 4 s each: `detail-hi.mp4` (2560×1440) without FX → the same with zoom ×2 → **the same zoom on `detail.mp4` (1280×720, there is no margin over the project)** → `detail-hi.mp4` with VHS and zoom. **Events 2 and 3 are the main comparison**: an identical chain, different files. In event 2 the timecode under the zoom is readable (decoding runs at 2560×1440); in event 3 it is mush, and this is honest: there are no details in the file. The steps are printed by `kt-cli probe 05-decode-scale.kt 4 6`. |
| `06-color.kt` | R.47 Round 2, point-wise: ColorGrade (contrast + saturation + hue) → Duotone (sepia tones) → Posterize 4 → **vignette INSIDE a series** (grid → vignette → zoom ×2): the darkening zooms together with the picture (the stage coordinate), the exit corners are lighter than a direct vignette. |
| `07-fx-barriers.kt` | R.47 Round 3, barriers: Sharpen (the timecode rings) → Pixelate 16 → ChromaticAberration (coloured fringes towards the edges) → RadialBlur (rays from the centre) → **DropShadow on the cut-out key of green.mp4** (a shadow offset by 14 px under the figure) → Halftone (a newspaper screen, dots larger in the dark areas). |
| `08-warp.kt` | R.47 Round 4, warps: Ripple with a CURVE of phase (the wave runs all 4 s) → CornerPin with curves of the corners (the frame "sets itself" to full by 3 s) → LensDistort −0.5 (pincushion) → Twirl → Kaleidoscope + zoom ×1.5 and Cylinder + zoom ×1.3 (**concatenation: the warp and the zoom are one merged pass**, sharpness is not lost). |

```bash
KT_VIDEO_GPU=0 cargo run -p kt-app
```
