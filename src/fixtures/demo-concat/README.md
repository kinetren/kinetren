# Демо: конкатенация трансформов (Р.44) и смягчение барьеров (Р.45)

Проекты для проверки глазами и сравнения со старым движком. Медиа
генерируется системным ffmpeg (в репозиторий не коммитится):

```bash
./gen-media.sh
```

Открывать в `kt-app` (или рендерить `kt-cli export <проект> out.mp4`).
Проекты перегенерируются тестом
`cargo test -p kt-cli --test gen_demo -- --ignored`.

| Проект | Что смотреть |
|---|---|
| `01-net-identity.otio` | Три события по 4 с: чистый исходник → мозаика grid 2×2 + pan3d-зум ×4 (нетто-масштаб 1:1) → grid 2×2 + Pan-зум ×2. **Все три обязаны быть одинаково резкими** (тест: читается бегущий таймкод testsrc2). До Р.44 события 2-3 были мыльными — сетка растеризовалась, зум увеличивал кашу. |
| `02-user-parallax.otio` | Сценарий владельца Р.44 с кривыми: grid → pan3d (параллакс приходит в норму к 4 с) → grid → pan3d (зум ×4 к 7.5 с устраняет сетки). **Финал резкий**, таймкод читается. |
| `03-barrier.otio` | Р.45, K×-барьеры: grid → VHS → зум ×2; grid → Edges → зум ×2; чистый VHS (референс вида). **Фактура эффекта переживает зум**: скан-линии/контуры чёткие, таймкод читается; вид VHS в событии 1 совпадает с референсом события 3. |
| `04-pointwise.otio` | Р.45, поточечные в серии (на green.mp4): чистый greenscreen (референс) → grid → greenscreen → зум (ключ работает, картинка резкая) → grid → noise → зум (зерно прибито к своему шагу — растянуто зумом блоками). |

Проверка CPU-эталона (Pan3d с Р.44 считается и без GPU):

```bash
KT_VIDEO_GPU=0 cargo run -p kt-app
```

Сравнение со старым движком: собрать `kt-cli` на коммите до слияния
(`git worktree add /tmp/kt-old 49fdfbc`), отэкспортировать те же .otio
обоими бинарями (старому — АБСОЛЮТНЫЙ путь к проекту: п.316) и сравнить
кадры.
