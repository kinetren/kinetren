# Демо: конкатенация трансформов (Р.44), смягчение барьеров (Р.45),
# ступень декода (Р.46)

Проекты для проверки глазами и сравнения со старым движком. Медиа
генерируется системным ffmpeg (в репозиторий не коммитится):

```bash
./gen-media.sh
```

Открывать в `kt-app` (или рендерить `kt-cli export <проект> out.mp4`).
Проекты перегенерируются тестом
`cargo test -p kt-cli --test gen_demo -- --ignored`.

| Проект | Что смотреть |
|---|---|
| `01-net-identity.kt` | Три события по 4 с: чистый исходник → мозаика grid 2×2 + pan3d-зум ×4 (нетто-масштаб 1:1) → grid 2×2 + Pan-зум ×2. **Все три обязаны быть одинаково резкими** (тест: читается бегущий таймкод testsrc2). До Р.44 события 2-3 были мыльными — сетка растеризовалась, зум увеличивал кашу. |
| `02-user-parallax.kt` | Сценарий владельца Р.44 с кривыми: grid → pan3d (параллакс приходит в норму к 4 с) → grid → pan3d (зум ×4 к 7.5 с устраняет сетки). **Финал резкий**, таймкод читается. |
| `03-barrier.kt` | Р.45, K×-барьеры: grid → VHS → зум ×2; grid → Edges → зум ×2; чистый VHS (референс вида). **Фактура эффекта переживает зум**: скан-линии/контуры чёткие, таймкод читается; вид VHS в событии 1 совпадает с референсом события 3. |
| `04-pointwise.kt` | Р.45, поточечные в серии (на green.mp4): чистый greenscreen (референс) → grid → greenscreen → зум (ключ работает, картинка резкая) → grid → noise → зум (зерно прибито к своему шагу — растянуто зумом блоками). |
| `05-decode-scale.kt` | Р.46, ступень декода. Четыре события по 4 с: `detail-hi.mp4` (2560×1440) без FX → он же с зумом ×2 → **тот же зум на `detail.mp4` (1280×720, запаса над проектом нет)** → `detail-hi.mp4` с VHS и зумом. **События 2 и 3 — главное сравнение**: одинаковая цепочка, разные файлы. В событии 2 таймкод под зумом читается (декод идёт в 2560×1440), в событии 3 — мыло, и это честно: деталей в файле нет. Ступени печатает `kt-cli probe 05-decode-scale.kt 4 6`. |
| `06-color.kt` | Р.47 Кв2, поточечные: ColorGrade (контраст+сатурация+hue) → Duotone (сепия-краски) → Posterize 4 → **виньетка ВНУТРИ серии** (grid → vignette → зум ×2): затемнение зумится вместе с картинкой (координата стадии), углы выхода светлее прямого виньетажа. |
| `07-fx-barriers.kt` | Р.47 Кв3, барьеры: Sharpen (таймкод звенит) → Pixelate 16 → ChromaticAberration (цветные каёмки к краям) → RadialBlur (лучи от центра) → **DropShadow на вырезанном ключе green.mp4** (тень со сдвигом 14 px под фигурой) → Halftone (газетный растр, точки крупнее в тёмном). |
| `08-warp.kt` | Р.47 Кв4, варпы: Ripple с КРИВОЙ phase (волна бежит все 4 с) → CornerPin с кривыми углов (кадр «устанавливается» в полный к 3 с) → LensDistort −0.5 (подушка) → Twirl → Kaleidoscope+зум ×1.5 и Cylinder+зум ×1.3 (**конкатенация: варп и зум — один слитый проход**, резкость не теряется). |

Проверка CPU-эталона (Pan3d с Р.44 считается и без GPU):

```bash
KT_VIDEO_GPU=0 cargo run -p kt-app
```

Сравнение со старым движком: собрать `kt-cli` на коммите до слияния
(`git worktree add /tmp/kt-old e789f47`), отэкспортировать те же проекты
обоими бинарями (старому — АБСОЛЮТНЫЙ путь к проекту: п.316) и сравнить
кадры.
