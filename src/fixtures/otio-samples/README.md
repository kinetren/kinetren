# Third-party .otio samples (cross-render conformance, test 158)

Copies of `tests/sample_data` from the upstream OpenTimelineIO
(github.com/AcademySoftwareFoundation/OpenTimelineIO), licence Apache-2.0 — the
text is in `LICENSE` next to them.

Pin: **73803eff1dbf86b82bcf97179567a243f4036b90** (2026-06-23).
Update: `src/scripts/fetch-otio-samples.sh` (fix `PIN` there and here);
upstream drift is visible with a plain `git diff`.

The files are committed deliberately (the user's decision of R.25 item 2): "from the internet" —
is about the origin of the material, not about the way it is delivered; the test MUST work
offline and deterministically.

## What is valuable in them (why exactly these were chosen)

| File | Constructs |
|---|---|
| `simple_cut.otio` | 4 splices, ExternalReference; **Clip-004 without `source_range`** — the duration is taken from `available_range` |
| `multiple_track.otio` | 3 tracks, Gaps, ExternalReference |
| `multitrack.otio` | 3 tracks, 7 Gaps, MissingReference |
| `preflattened.otio` | one track, Gaps — the reference of "flattened" editing |
| `transition_test.otio` | 3 SMPTE_Dissolve, including **at the edge of a track** (fade-in), clips with `media_reference: null` |
| `screening_example.otio` | EDL-style, MissingReference, `Marker.3` |
| `nested_example.otio` | **nested Stacks**, `LinearTimeWarp`, `FreezeFrame` |
| `premiere_example.otio` | a Premiere export: `Marker.3`/`Color.1`/`GeneratorReference`, rate 15 and 30 |
| `generator_reference_test.otio` | the archaic schema `Sequence.1` (the ancestor of `Track`) |

Synthetic sources for them are NOT committed: they are generated by
`src/scripts/otio-cross-prepare.py` (solid colours from a palette) into a temporary
directory of the test.
