# Spec Delta

## MODIFIED Requirements

### Requirement: Режим целей — слой «всё, что ниже» по строкам

Умолчание режима целей SHALL быть «всё, что ниже строки морфера»; «ниже» считается по
ПОРЯДКУ СТРОК, а порядок строк SHALL быть состоянием модели — порядком вектора дорожек-объектов
(ходит через undo, поднимает грязность содержимого); морф- и камерные дорожки — те же
объекты без уровня и цепочки. Порядок наложения слоёв SHALL быть снизу вверх (нижний слой
применяется первым), внутри одной строки — по id. Морфер остаётся пер-клиповым и
применяется ДО стадии дорожки (цепочка, уровень, режим наложения дорожки видят уже
изменённые клипы). Замороженный список целей MUST быть непустым; пустое множество целей у
слоя законно.
Почему: пользователь просил «не мучаться с выделением»; перестановка строк меняет
картинку — значит она монтаж, а не удобство UI; порядок как вектор дорожек убирает второй
источник правды (`lane_order` рядом со счётчиками).

#### Scenario: Слой накрывает то, что под ним, снизу вверх
- **WHEN** морф-строка стоит снизу списка, затем поднимается наверх; два слоя на разных строках
- **THEN** снизу слой не накрывает ничего, сверху — всё под собой; видео-слой не трогает аудио; нижний слой применяется первым; перестановка строк переворачивает порядок эффектов и откатывается undo
- **TEST** t235 (`src/libs/kt-model/tests/morph_slice.rs`)

#### Scenario: Порядок строк — состояние модели (контейнер, capability `ui-timeline`)
- **WHEN** строки переставлены командой
- **THEN** порядок переживает undo/redo, вставка/удаление дорожки сдвигает его внутри команды, мусор нормализуется; в файле порядок — порядок треков, отдельного поля нет
- **TEST** t241, t49 (`src/libs/kt-model/tests/lane_order.rs`), t241 (`src/libs/kt-otio/tests/convert.rs`)

#### Scenario: Окно морфера показывает режим и время
- **WHEN** окно морфера открыто в режиме слоя и в режиме замороженного списка
- **THEN** в режиме слоя показано объяснение, что накрывается; замороженный список — поимённо; галка «по времени» правит модель одним шагом истории
- **TEST** t242 (`src/apps/kt-app/src/layout_tests.rs`)

#### Scenario: Морфер до стадии дорожки
- **WHEN** морф-слой красит клипы дорожки, у которой стоит цепочка дорожки с виньеткой
- **THEN** виньетка ложится на уже покрашенный композит дорожки; порядок «морфер → дорожка» не зависит от положения морф-строки относительно этой дорожки выше по списку
- **TEST** t736 (`src/libs/kt-engine/tests/track_video.rs`)
