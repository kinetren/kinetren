# Tasks

Числа «до» (замер 02.10.2026, подробности — `proposal.md`): `.otio` против сериализации
модели — 17× на плоском проекте, 501× и 929× на вложенных сценах; у владельца три ленты
дали 15 220 клипов и 115 МБ, и автосейв пишет это регулярно. Порядок стадий: формат →
passthrough → двери → автосейв → вычистка и проверка; каждая проверяема отдельно. Каждая
стадия заканчивается коммитом по-русски (правило автокоммита), вся работа — `finish.sh`.

## 1. Формат проекта: запись, чтение, версия

- [ ] 1.1 Завести запись и чтение проекта своим форматом (`src/libs/kt-model`, точка входа `project_file`): ПОСТРОЧНЫЙ JSON модели (требование владельца — индексируемость в git; компактный отвергнут, см. 1.5), на корне признак `kinotrain` и версия. Проверка: t811 (`src/libs/kt-model/tests/project_file.rs`) — круг поле-в-поле и второй круг байт-в-байт на проекте с лентами, морферами, камерами, переходами и публичными параметрами.
- [ ] 1.2 Размер файла зависит от МОДЕЛИ, а не от числа экземпляров. Проверка: t810 — прирост на каждый новый экземпляр ленты равен размеру ссылки, а не тела; на сцене «лента из 10 клипов, два уровня по 8 экземпляров» файл на порядки меньше того же проекта в `.otio` (ориентир замера — 3.9 КБ против 1.97 МБ).
- [ ] 1.3 Версия: больше нынешней — отказ с номером и адресом двери, частичное чтение запрещено; меньше — миграция на чтении, односторонняя. Проверка: t812 — три входа (версия вперёд, версия назад, файл обмена) дают три названных исхода.
- [ ] 1.4 Атомарная запись и исход-тип: обрыв между временным файлом и переименованием оставляет либо прежний проект целиком, либо новый целиком; отказ не выглядит успехом. Проверка: t813; сторож ревизии (`write_project_guarded`) переиспользуется, а не дублируется.
- [ ] 1.5 Файл индексируем в git: построчный JSON с детерминированным порядком; passthrough — по отсортированным ключам. Проверка: t822 — правка одного события меняет единицы строк (не файл), два сохранения одной модели байт-в-байт равны, с чужим passthrough — тоже; сторож отвергает компактную (однострочную) запись.
