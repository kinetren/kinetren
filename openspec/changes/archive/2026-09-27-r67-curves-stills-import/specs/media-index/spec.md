# Spec Delta

## ADDED Requirements

### Requirement: Одиночная картинка — источник с кадром на любой длительности; пропавшая — заглушка, не «Loading…»

Одиночный файл картинки (JPEG, PNG — включая PNG с альфой, как читает системный FFmpeg)
SHALL быть полноправным источником: у него ОДИН кадр, отдаваемый на ЛЮБОЙ запрошенный тик
(нет ни сетки кадров, ни конца материала — событие любой длительности показывает картинку
целиком), аудио — тишина, длительность «практически бесконечная» (как у заглушки),
ступень декода — от натива картинки, alpha PNG — прозрачность в композите. Кадр SHALL
дойти до превью не позже, чем кадр видео того же размера: «Loading…» (скрим неполноты
дольше 180 мс) над событием-картинкой MUST NOT висеть после первого прочтения файла.
Отсутствующая картинка SHALL получать ту же заглушку, что видео (тёмный кадр с именем
файла), и заглушка — ПОЛНЫЙ кадр: скрим «Loading…» над ней MUST NOT появляться вовсе;
человек видит имя пропавшего файла в кадре сразу, а не при просмотре. Фикстуры картинок
(JPEG, PNG с альфой) SHALL генерироваться `fixtures/gen.sh` и покрывать чтение, план,
превью и экспорт.
Почему: Р.67, владелец: «статичные картинки не отображаюся, вообще.. там вечный
Loading... мало того что не работает - так ты еще об этом узнаешь только в момент
просмотра». Фикстур с картинками в проекте не было ни одной — путь никогда не был под
тестом; заметка F-MED-003 мерила одиночный PNG вручную в Р.52.

#### Scenario: Картинка читается, планируется, показывается и экспортируется
- **WHEN** событие 10 с на JPEG-фикстуре и событие на PNG с альфой поверх цветного фона; спрашивается кадр на 0, 3.7 и 9.96 с; открывается в харнессе; экспортируется 1 с
- **THEN** источник открыт, на всех трёх тиках один и тот же кадр с пикселями картинки; в плане кадра событие есть; в харнессе превью укомплектовано до 180 мс (скрима «Loading…» нет); PNG с альфой даёт фон сквозь прозрачные пиксели; экспорт содержит кадры картинки (пиксельная проба); детерминизм — байт-в-байт
- **ПУТЬ** перетащить `still.jpg` на таймлайн → событие появилось → кликнуть по нему → в превью сразу картинка, без «Loading…» → потянуть край события до 20 с → картинка на месте на всей длине
- **TEST** t796 (`src/libs/kt-media/tests/ffmpeg_conformance.rs`), t796b (`src/libs/kt-engine/tests/stills.rs`), t796c (`src/apps/kt-app/src/layout_tests.rs`), живой сценарий `src/scripts/live/stills.py`

#### Scenario: Пропавшая картинка — заглушка с именем, без «Loading…»
- **WHEN** проект ссылается на несуществующий `logo.jpg`; открывается в харнессе; курсор ставится на событие; проходит 500 мс
- **THEN** в кадре тёмная заглушка с текстом `logo.jpg` (пиксельная проба надписи), уведомление называет файл; скрима «Loading…» нет ни в одном кадре (на прежнем коде — вечный); возврат файла на место подменяет заглушку картинкой без переоткрытия
- **ПУТЬ** открыть проект без картинки → на событии сразу тёмный кадр с именем файла, колокольчик с уведомлением → положить файл на место → картинка появилась сама
- **TEST** t796d (`src/apps/kt-app/src/layout_tests.rs`), живой сценарий `src/scripts/live/stills.py`
